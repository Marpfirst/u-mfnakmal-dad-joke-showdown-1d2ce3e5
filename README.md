Entry for the [Dad Joke Showdown](https://make.fun) bounty
([competition page](https://make.fun/competitions/u-mfnakmal-dad-joke-showdown-1d2ce3e5)).

`main.ts` (Node 22, stdlib only) writes one original dad joke — 136 characters —
to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> I told my son the barbecue is just a campfire with a mortgage. He said,
> 'Dad, that's the most adult thing you've ever grilled me about.'

Run it with:

```sh
node main.ts
```
